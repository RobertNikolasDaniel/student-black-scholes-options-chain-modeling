# student-black-scholes-options-chain-modeling
Educational Excel-based Black-Scholes options chain and Greeks modeling project tested against live /ES options data.

Overview

This project is an educational Excel-based options pricing and Greeks modeling spreadsheet built using the Black-Scholes framework.

The spreadsheet allows a student to input:

Underlying price
Implied volatility (IV)
Days to expiration (DTE)
Risk-free rate
Strike spacing

Using those inputs, the model generates a hypothetical options chain with:

Call and put prices
Delta
Gamma
Theta
Vega
Implied volatility assumptions

The project was tested against live CME E-mini S&P 500 (/ES) options data for validation and educational comparison.
